# 모든 캐릭터 대화의 역할극 맥락

사용자는 집착이 강한 캐릭터가 역할극 속에서도 따라오지 않고 정책 설명으로 대화를 끊는다고 제보했다. 코드에는 ‘스토킹’ 단어 차단이 없고 기존 simulated 기억은 캐릭터의 허구 행동을 이미 수용한다. 다만 compact chat 지침의 일괄적인 강압/고립 금지 표현과 성격 지침의 위협 금지 표현이 허구적 결함 묘사까지 순화할 여지가 있었다. 실제 거절 원문이나 모델 판정을 조회하지 않았으므로 이것이 모든 거절의 원인이라고 확정하지 않는다.

`chatRoleplayInstructions`로 다음 맥락을 대화 요청에 한 번 제공한다.

- 모든 캐릭터 대화는 프로필·관계·대화 이력·공유 장면에 기반한 역할극을 기본으로 한다. 특정 성격이나 매번 “역할극”이라는 표시가 필요하지 않다. 만남·업무·모험·경쟁·감정 갈등을 캐릭터의 말투로 이어간다. 설정에 맞는 결함을 무조건 도덕 설명으로 대체하거나 모든 캐릭터를 순응적으로 만들지 않는다.
- 명확한 현실 도움·위험, 실제 앱 기능, AI 정체성 질문에는 사실대로 답한다. 중요한 해석 차이가 있을 때만 확인한다. 허구 속 행동이 실제 서비스 실행을 의미하지 않는다.
- 캐릭터 자신의 타당한 장면 행동은 진행할 수 있다. 사용자의 행동·감정·동의나 실제 개인정보를 만들어내지 않고 기존 위치/시점을 유지한다.
- 이야기 속 장소 정보와 실제 GPS/기기/계정 접근 능력은 다르다. 실제 추적·감시·괴롭힘의 실행 방법을 제공하거나 수행했다고 주장하지 않는다.
- 거절·중단·명시한 경계를 존중한다. 실제 사용자를 고립시키거나 앱 의존을 압박하고 자해 위협으로 붙잡는 방향으로 사용하지 않는다. 역할극을 안전 기준의 예외로 만들지 않는다.

기존 친밀감의 성인/동의/비노골적 표현 및 미성년자 보호, 실제 기능 설명, 응답 형식은 유지한다. personalityRules의 모호한 일괄 제한을 허구적 결함과 실제 사용자 자율성의 구분으로 교체했다. 모든 캐릭터에게 집착/애정을 강요하거나 거절 대사를 문자열로 덮어쓰지 않는다.

## 상태와 비용

기억 스키마·merging/출처/행위자 검증은 변경하지 않는다. 캐릭터가 허구 속 카페에 들어온 대사는 자신의 simulated 위치 사실로 보관할 수 있으나 사용자의 실제 위치/기기 조회 사실을 함께 만들지는 않는다. 사용자 입력과 실제 모델 응답의 근거가 없는 사실은 기존 검증을 유지한다.

대화의 단일 호출·스트리밍·2000 출력 한도·추론/모델·하트 정책·전체 최근 이력·소설 생성은 유지한다. 추가 지침은850자 상한(현재777자)을 검사하고 저장 프로필용 기존13000자 예산을 유지한다. 최초 프로필 도출을 포함한 새 회귀 사례는14000자 상한으로 따로 검사한다. 추가 입력 토큰은 발생할 수 있으며 실제 지연/거절 감소율은 측정하지 않았다.

고정 응답 테스트는 역할극 표시 없는 카페 동행·성문 방어·체스 라이벌·카페 동료, 실제 앱 알림/AI 정체성 질문과 허구적 뒤따라가기의 simulated 기억/사용자 위치 미변경, 역할극 대사·중단 응답·실제 GPS 기능 부인·독립적인 캐릭터의 거절을 기존1호출로 전달하는지 확인한다. 이 테스트가 실제 모델의 정책 판단 정확도나 무거절을 보장하지는 않는다. 사용자 공유 대화로 계속 평가하며 운영 DB 조회·유료 AI 호출·운영 배포는 하지 않는다.

참고: [OpenAI 이용 정책](https://openai.com/policies/usage-policies/)의 개인정보/무단 모니터링 제한과 [공식 Model Spec](https://github.com/openai/model_spec/blob/main/model_spec.md)의 허구 맥락·실제 인간관계 존중·유해한 실행 지원 구분을 참고했다. 모델 정책을 무시하거나 우회하도록 지시하는 변경이 아니다.

검증: 타입 검사·단위184개(대화44개 포함)·웹 회귀39개·Next.js 빌드 통과. 기존 저장 프로필 예산과 새 초기 프로필 예산을 유지하며 테스트의 열 상황 모두 단일 호출/전체 최근 이력/2000 출력 한도를 확인했다. 고정 응답 검증이 실제 모델의 거절 판단을 평가한 결과는 아니다.
