# 이미지 구도 선택

구도 상세 입력은 소설 삽화 생성에만 제공한다. 캐릭터 생성과 대화 이미지는 구도를 자동으로 정하며, 대화의 기존 장소·의상 확인은 유지한다. 계정 기능을 끈 데모에서도 소설 화면에만 이미지 구도 접기 영역을 제공한다.

- 촬영 범위: 자동, 얼굴 클로즈업, 바스트샷, 상반신, 전신, 부분 클로즈업.
- 각도: 자동, 정면, 사선, 옆모습, 위에서, 아래에서.
- 인물이 있으면 시선과 표정, 얼굴 외 구도이면 자세·동작을 지정할 수 있다.
- 부분 클로즈업은 집중 대상이 필수다. 다른 구도로 전환하면 숨겨진 집중 대상을 지운다. 얼굴로 전환하면 숨겨진 자세를 지운다.
- 인물 없는 장면은 자동 또는 부분 클로즈업을 사용한다. 얼굴·부분 클로즈업은 의상 입력이 선택이며 장소 등 기존 장면 확인은 유지한다.

`lib/characters/framing.ts`의 제한된 스키마를 소설 삽화의 클라이언트와 서버에서 검증한다. 삽화는 scene.selection.framing으로 전달하며, 자유 입력도 기존 내용 검토 대상에 포함한다. 설명 정리 호출과 최종 이미지 프롬프트 양쪽에서 선택 구도를 적용하며 보이지 않는 다리·의상을 설명하기 위해 화면을 넓히지 않도록 한다. 기존 참고 이미지의 인물·화풍은 유지하고, 구도는 선택값을 우선한다.

캐릭터 생성 폼에는 구도 상태/입력/필수 대상 검증을 두지 않고 요청에도 framing을 보내지 않는다. 대화 확인 팝업에도 구도·각도·시선·표정·동작/집중 대상 입력을 두지 않는다. 서버는 이전 브라우저가 보내는 생성/대화의 구도 필드를 검증 전에 제거하거나 무시해 숨은 설정이 적용되거나 누락된 집중 대상 때문에 실패하지 않게 한다. 삽화의 필수 대상 검증은 유지한다. 자동 구도가 전신 고정을 뜻하지는 않으며 장면에 맞게 AI가 선택한다.

이미지 해상도 720×1280, 환경변수의 품질 설정, 기존 하트 비용과 성공 후 차감 방식을 유지한다. 추가 AI 호출은 없고 삽화의 선택값에 따른 소량의 입력만 추가된다. 자동·선택 없음은 추가 구도 지침을 만들지 않는다. 실제 모델이 모든 구도를 정확히 따르는지는 실생성으로 확인해야 한다.

검증: 생성/대화 상세 필드 및 요청 구도 값 제거, 삽화 선택값·필수 대상·요청 전달·구도 우선순위, 구형 생성/대화 요청의 잘못된 구도 값 무시와 기존 호출 수를 단위 테스트와 모의 API 브라우저 테스트로 확인한다. 실제 유료 이미지 생성이나 운영 DB 변경은 수행하지 않는다.

소설 구도 필드가 긴 확인 팝업은 세로 스크롤하며 가로 넘침이 없음을 검사한다. 데모 구도 메뉴도 소설 화면에서만 이미지 버튼 옆에 열어 본문 영역 높이를 유지한다.

운영 배포는 이 변경에 포함하지 않는다.
