# 이미지 구도 선택

캐릭터 생성 폼과 대화 장면·소설 삽화의 생성 확인 팝업에서 공통 구도를 선택한다. 계정 기능을 끈 데모 화면은 이미지 구도 접기 영역을 사용한다.

- 촬영 범위: 자동, 얼굴 클로즈업, 바스트샷, 상반신, 전신, 부분 클로즈업.
- 각도: 자동, 정면, 사선, 옆모습, 위에서, 아래에서.
- 인물이 있으면 시선과 표정, 얼굴 외 구도이면 자세·동작을 지정할 수 있다.
- 부분 클로즈업은 집중 대상이 필수다. 다른 구도로 전환하면 숨겨진 집중 대상을 지운다. 얼굴로 전환하면 숨겨진 자세를 지운다.
- 인물 없는 장면은 자동 또는 부분 클로즈업을 사용한다. 얼굴·부분 클로즈업은 의상 입력이 선택이며 장소 등 기존 장면 확인은 유지한다.

`lib/characters/framing.ts`의 제한된 스키마를 클라이언트와 서버에서 검증한다. 초기 생성은 multipart의 framing, 후속 생성은 scene.selection.framing으로 전달한다. 자유 입력도 기존 내용 검토 대상에 포함한다. 설명 정리 호출과 최종 이미지 프롬프트 양쪽에서 선택 구도를 적용하며 보이지 않는 다리·의상을 설명하기 위해 화면을 넓히지 않도록 한다. 기존 참고 이미지의 인물·화풍은 유지하고, 구도는 선택값을 우선한다. 새 캐릭터 작성 시 구도도 자동으로 초기화한다.

이미지 해상도 720×1280, 품질 medium, 기존 하트 비용과 성공 후 차감 방식을 유지한다. 추가 AI 호출은 없고 선택값에 따른 소량의 입력만 추가된다. 자동·선택 없음은 추가 구도 지침을 만들지 않는다. 실제 모델이 모든 구도를 정확히 따르는지는 실생성으로 확인해야 한다.

검증: 선택값·필수 대상·요청 전달·구도 우선순위·숨겨진 값 초기화·기존 호출 수를 단위 테스트와 모의 API 브라우저 테스트로 확인한다. 실제 유료 이미지 생성이나 운영 DB 변경은 수행하지 않는다.

타입 검사와 단위 테스트 174개, 웹 회귀 39개, 계정 화면 관련 3개, 모바일 화면 1개를 통과했다. 구도 필드가 긴 확인 팝업은 세로 스크롤하며 가로 넘침이 없음을 확인했다. 데모 구도 메뉴는 이미지 버튼 옆에서 열어 대화 영역 높이를 유지한다. 모바일 번들 및 Android 동기화를 완료했다.

Next.js 배포 빌드도 통과했다. 운영 배포는 수행하지 않았다.
