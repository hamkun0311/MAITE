# 소설 지침 복잡도 검토와 통합

## 검토 결과

개선 지침의 단순 누적은 품질을 떨어뜨릴 가능성이 있다. 실제 코드에서는 같은 역할·행동·근거 규칙을 집필/검수 이름으로 반복하고, 집필용 지침에도 말투 기억을 추출하라는 요구가 들어 있었다. 감정과 움직임을 매 문장 상세히 설명하게 만들거나, 추측·비유·인물의 무모한 선택을 무조건 오류로 취급할 위험도 있었다. 이는 코드상 확인한 중복/역할 혼재와 그에 대한 위험 판단이며, 실제 모델 품질 저하의 원인을 실험으로 확정한 결과는 아니다.

## 변경

`lib/novel/quality.ts`의 공통 원칙 한 곳으로 정리했다. 기존 Scene/Meaning/Causal 계열의 누적 상수 여섯 개를 제거하고, 말투 규칙은 대화 의미와 지속 말투만 남겼다. 같은 요청 안에 공통 원칙은 한 번만 들어간다.

1. 사실과 시점: 역할·상태 소유자·인원/결과·확정 관계를 유지한다. 실제 사실과 관점 인물의 믿음/바람/걱정/가정을 구별한다. 보호 행동만으로 숨은 사랑을 확정하지 않지만, 이미 성립한 관계·근거 있는 전지적 서술은 허용한다. 과거 발화의 뜻을 유지하는 바꿔 말하기는 허용하며 없던 약속/명령을 만들지 않는다.
2. 의미: 화자/상대/혼잣말·생략 주어·질문/반박 대상과 비유의 의미를 확인한다. 양립 가능한 사실을 잘못 부정하지 않으며 진짜 거절·정도 강조·의도적 회피는 허용한다.
3. 물리적 연결: 위치/시간/이동·인원 처리·무기/능력·자세/거리/힘을 연결한다. 모든 움직임을 중계하거나 부상자 모두의 이동을 금지하지 않는다.
4. 동기와 결과: 중요한 사건이 기존 목표와 복합 감정에 영향을 주고, 선택과 결과 또는 진행 중인 목적에 이어지게 한다. 위험한 만남을 기대한다는 이유로 위험 자체를 지우지 않는다. 성격에 맞는 충동/오판은 허용하고 결과를 보여준다. 같은 몸짓 해석만 반복해 사건이 정체되지 않도록 한다.

집필은 위 원칙을 자연스러운 장면으로 작성하고 필요한 연결만 추가한다. 감정 순서를 매 문단 강제하거나 점검표를 원고로 출력하지 않는다. 검수는 별도 task에서 기존 sceneAudit 네 항목을 판정하되 현재 원고 근거가 있는 의미/인과/연속성 문제만 실패시킨다. 문체 취향·그럴듯한 추론·인물의 의도된 실수는 실패 사유가 아니다. 말투 기억 추출은 검수/통합 모드의 메타데이터 단계로 옮겼다. integrated는 집필에 이미 있는 공통 원칙을 다시 붙이지 않고 검수/기억 task만 추가한다. JSON 모드에서 메타데이터는 본문 밖 별도 필드에 둔다.

기존 개념 우선순위·출처 검증·성격·공유 시간선·최대1회 보정·실패 미반영·정상 호출 수·sceneAudit 구조는 유지한다. 모델·추론·분량·출력 한도·UI·가격·DB는 바꾸지 않는다. 과거 회차와 미래 회차를 추가로 조회/전송하지 않는다.

## 지침 크기

동일한 공통 품질 지침 부분을 변경 전후 측정했다. 전체 요청이나 스키마/원고/기억을 포함한 토큰 사용량이 아니다.

| 품질 지침 부분 | 이전 문자 수 | 변경 후 문자 수 | 감소 |
| --- | ---: | ---: | ---: |
| 집필 | 5,778 | 3,592 | 37.8% |
| 독립 검수 | 8,414 | 3,955 | 53.0% |
| 통합 모드 | 8,829 | 4,829 | 45.3% |

현재 수치는 위치/위험 해소/소품/시야와 청취/시간 전환의 연결 보완을 포함한다. 직전 통합본 대비 집필 +219자·독립 검수와 통합 각각 +247자이며 별도 품질 지침 묶음을 추가하지 않았다. 이는 문자 수이고 실제 토큰/시간 변화율은 아니다.

이후 추가한 [짧은 컨셉 자동 극화](NOVEL_CONCEPT_ADAPTATION.md)는 검수 사례 규칙과 구분되는 제품 기본 지침1282자다. 위 표는 공통 품질 부분만 세며, 제품 지침까지 합산하면 집필4874/검수5237/통합6111자다. 두 지침 모두 요청당1회만 포함하도록 검사하고 별도 호출/스키마는 추가하지 않는다. 추가 입력이 없다고 설명하지 않는다.

길이 상한 회귀 검사는 집필 3,600자·검수 4,200자·통합 5,000자로 둔다. 앞으로 새로운 사례는 먼저 회귀 사례로 추가하고, 공통 원칙의 빈틈을 확인한 뒤 기존 원칙을 수정한다. 과거 예시 문구와 금지 규칙을 계속 덧붙이지 않는다.

## 검증 범위

기존 병실/역할/말투/상태 소유자/가정법/인원/공격 수단 사례를 유지했다. 복합 감정을 지우며 위협을 단순 점검으로 바꾸는 오류, 한 번의 보호를 근거 없이 사랑의 확정 사실로 바꾸는 오류의 기존 보정 경로도 확인한다. 정상 사례에서는 기대와 걱정, 동기가 있는 무모함과 그 대가, 확정하지 않은 감정 해석을 유지하며 추가 재작성 없이 통과한다.

고정 응답 테스트는 지침 전달·확정/보정 경로·입력 길이·기존 원고 보존을 검증한다. 실제 모델의 문학적 품질 동등성이나 향상을 보장하지 않는다. DB 조회·기존 원고 수정·유료 생성·운영 배포 없이 수행하며, 실제 품질은 사용자가 다음에 공유하는 생성 원고로 계속 확인한다.
