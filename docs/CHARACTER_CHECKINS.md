# 캐릭터 안부 — 앱 자체 예약 알림

2026-11-18: Firebase 푸시에서 Capacitor Local Notifications로 전환했다. Firebase 프로젝트·google-services.json·발송 키·서버 Cron은 필요 없다.

**현재 테스트 설정은 24시간 대신 3분이다.** `lib/notifications/timing.ts`의 `CHECKIN_DELAY_MINUTES`를 앱 예약·설정 화면·서버 검증이 공유한다. 아래 24시간 설명은 운영 기준이며, 운영 복귀 전에는 이 값을 1440으로 바꾸고 서버와 Android를 함께 갱신한다. 현재도 야간 제한(22~10시)과 하루 1회·답장 전 재발송 금지는 유지한다. 테스트 시 앱 알림을 켜고 해당 캐릭터에게 새 답장을 보낸다. 야간에 3분을 확인하려면 야간 제한을 직접 꺼야 한다. OS 비정확 알람이라 정확히 180초에 표시됨을 보장하지 않는다.

## 동작

- 마지막으로 대화한 캐릭터의 완료된 대화 저장 시각을 기준으로 24시간 뒤 안부를 한 번 예약한다. 캐릭터가 여러 명이어도 기기에는 계정당 예약 하나만 유지한다.
- 새 대화를 저장하면 기존 예약을 취소하고 새 대화 시각으로 갱신한다. 답장이 없는 동안에는 다음날에도 반복 예약하지 않는다. 안부를 보낸 캐릭터에게 답장해야 다음 안부가 가능하다.
- 마이페이지의 **앱 알림**, **야간 알림 제한**으로 설정한다. 기본 알림은 꺼짐, 야간 제한은 켜짐이다.
- 야간은 **한국시간 오후 10시~오전 10시**이다. 이 시간에 해당하는 예약은 오전 10시로 미룬다. 야간 제한을 끄면 이 조정을 하지 않는다.
- 문구는 `뭐해?`, `나 안 보고 싶어?`, `보고 싶어, 닉네임아/야.` 중 선택한다. AI 호출과 하트 차감은 없다.
- 알림을 누르면 해당 계정과 캐릭터를 확인한 뒤 대화 화면으로 이동한다. 다른 계정의 알림은 열지 않는다.
- 알림 끄기·캐릭터 삭제·로그아웃 시 남은 예약을 취소한다. 로그아웃 시 이미 표시된 안부 알림도 제거한다. 계정 변경 중 늦게 끝나는 작업은 새 계정에 예약하지 않는다.

## 저장과 동기화

앱은 예약과 답장 대기 상태를 계정별 기기 저장소에 보관한다. 앱 재시작 때 이미 지난 예약을 다시 예약하지 않는다. 예약 시각을 지난 기록은 앱 실행/알림 수신 시 서버로 동기화하여 대화에 표시한다. 네트워크가 없으면 기록을 보관하고 다음 연결 때 재시도한다. 서버는 본인 캐릭터와 대화 기록을 확인하고 계정·한국 날짜 중복을 차단한다.

이 기록의 `sent`는 예약 시간이 경과한 기기 기록을 뜻한다. OS가 실제로 알림을 보여주었음을 서버가 검증했다는 의미는 아니다. 권한 변경이나 절전 제한으로 표시되지 않았더라도 반복 안부는 보내지 않는다.

로컬 알림은 인터넷 없이 예약 시간에 표시할 수 있으나 OS 절전·강제 중지·기기 설정으로 지연되거나 누락될 수 있다. 일반 안부이므로 정확한 알람 특별 권한을 요구하지 않고 비정확 알람을 사용한다.

**다중 기기 한계:** 다른 기기에서 대화·설정을 변경해도 오프라인 기기에 이미 예약된 알림을 원격 취소할 수 없다. 각 기기가 앱을 열어 서버와 동기화할 때 반영된다. 서버 저장 내역은 계정당 하루 1개로 제한되지만, 오프라인 기기를 포함한 계정 전체의 실제 알림 표시 횟수를 엄밀하게 보장하는 방식은 아니다.

## 적용

1. 이미 실행한 `202611180003_character_checkins.sql`의 설정·활동·안부 테이블을 재사용한다. **추가 SQL 실행은 필요 없다.** 기존 서버 푸시용 테이블과 함수는 남아 있지만 호출하지 않는다.
2. 새 Next API 코드를 배포한다. 서버 Cron은 사용하지 않으며 이전 `/api/cron/checkins`는 410을 반환한다. 기존 예약이 별도로 있다면 중지한다. 이 프로젝트에서는 아직 서버 예약을 활성화하지 않았다.
3. `npm run mobile:sync` 후 Android 앱을 재빌드·설치한다.
4. 앱에 로그인하고 마이페이지에서 앱 알림을 켜며 Android 알림 권한을 허용한다. 이후 대화를 완료하면 OS에 예약한다.

웹에서도 계정 설정은 저장할 수 있지만 실제 로컬 알림 예약은 Android 앱에서 동작한다. 웹에서 바꾼 설정은 Android 앱의 다음 동기화 때 반영된다.

## 검증

- 24시간 예약과 대화 후 갱신, 한 번 경과 후 재예약 차단, 다른 캐릭터와의 대화가 답장을 대신하지 않는지 확인한다.
- 21:59, 22:00, 09:59, 10:00 KST의 야간 경계와 야간 제한 끄기를 확인한다.
- 재시작·오프라인·로그아웃·계정 변경·삭제 시 예약과 미동기화 기록을 확인한다.
- 실제 Android 기기의 권한과 절전 상태별 알림 표시를 별도로 확인한다.

공식 API: https://capacitorjs.com/docs/apis/local-notifications
